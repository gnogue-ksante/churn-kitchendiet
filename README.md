# Churn KitchenDiet — dashboard interne

Dashboard des demandes de désabonnement KitchenDiet (tickets Zendesk « Rétention », août → octobre 2026).

Le contenu de `index.html` est **chiffré** (AES-256-GCM, clé dérivée du mot de passe par PBKDF2-SHA256, 310 000 itérations).
Sans le mot de passe, le fichier ne contient aucune donnée lisible. Le mot de passe est communiqué en interne, jamais dans ce dépôt.

Document interne Aliive — ne pas diffuser.
